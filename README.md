# Geometry Figures OOP

## Название
Geometry Figures OOP — приложение для расчёта характеристик геометрических фигур.

## Описание
Лабораторная работа №2 по дисциплине «Алгоритмы и структуры данных на Python».
**Вариант 17 — Геометрические фигуры. Сложность: Rare.**

Реализованы классы:
- `Rectangle` — Прямоугольник;
- `Triangle` — Треугольник;
- `Trapezoid` — Трапеция.

Программа рассчитывает площадь, периметр и дополнительные характеристики
(диагональ, радиусы описанной/вписанной окружности, средняя линия),
а также сохраняет отчёт в формате **.docx** или **.xlsx**.

## Инструкции по запуску

```bash
# 1. Клонировать репозиторий
git clone <URL-репозитория>
cd geometry-figures-oop

# 2. Создать виртуальное окружение
python -m venv .venv

# Windows:
.venv\Scripts\Activate.ps1
# Linux / macOS:
source .venv/bin/activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Запустить программу
python main.py
